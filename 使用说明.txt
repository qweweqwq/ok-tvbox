OK影视个人接口 · 首版
制作日期：2026年10月2日

这套配置包含两个片库，每个都有“电影、电视剧、综艺”三个分类：
1. 央视公开片库：由本次编写的脚本读取央视官方公开点播。电视剧按剧集显示；综艺显示栏目内20分钟以上的近期节目。搜索使用央视全站公开视频，可能出现新闻或短片。
2. 备用片库：读取暴风资源的公开接口，并按电影、电视剧、综艺的分类筛选首页、列表、搜索和详情；电影和剧集可在“类型”筛选里切换。
实际片库、更新和视频画质由来源决定。这不是自行保存的视频库，也不能保证每部影片、每个旧集都可播放。
央视电视剧和综艺详情当前最多列出100集或期；长期栏目不会一次加载全部历史节目。

需要保留的三个文件
config.json
cctv.js
resources.js
三个文件必须放在同一目录，文件名不要修改。config.json 引用两个 JS 文件，并不是把 JavaScript 内容直接粘进 JSON。

方法一：使用自己的 GitHub 接口链接
配置已经上传至你的公开仓库：
https://github.com/qweweqwq/ok-tvbox
正式接口地址（复制完整这一行）：
https://raw.githubusercontent.com/qweweqwq/ok-tvbox/main/config.json
1. 在 OK影视：设置 → 点播 → 粘贴上面的正式接口网址 → 确定。
   电视版可通过地址输入框的二维码，用同一 Wi-Fi 下的手机输入网址。
2. 默认显示央视公开片库。需要其他影片时，切换到“备用片库”再搜索。
3. 接口地址应以 /config.json 结尾。仓库网页或带 /blob/ 的浏览页面不是接口。
4. 将来可以在自己的仓库中修改配置和脚本；保留这三个文件的名称和位置，接口地址即可保持不变。
本次已验证配置和两个脚本均可公开读取，并与本地测试文件内容一致；不需要重新创建仓库或重新上传。

方法二：先用本地文件
1. 在运行 OK影视的安卓手机或电视上，把三个文件放到 Download/ok-tvbox 目录。
2. 在 OK影视“设置 → 点播”的地址框输入：
   file://Download/ok-tvbox/config.json
3. 确保 App 有读取文件的权限。部分版本可直接点击地址框旁的文件选择按钮，选择 config.json。
4. 本地导入后，获取分类和播放视频仍需要联网。

遇到问题时
“接口加载失败”：先在浏览器打开配置链接，确认能看到 JSON；再确认同目录下两个 .js 文件都能打开。GitHub 在当前网络无法直连时，本地文件方法可先排除托管访问问题。
“能看到影片但无法播放”：换另一部、最新一集或另一片库。旧视频可能失效，来源也可能限制访问地区。
“显示空白”或“加载脚本失败”：记录 OK影视版本号和当前错误提示，本次已核对公开源码，但尚未在你的安装版本上实际导入。
上传或编辑配置时，不需要填写个人账号密码、网盘 Token 或视频平台登录信息。
